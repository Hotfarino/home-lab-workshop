# Asset and dependency provenance

- `assets/lab-blender-hardware.glb`: generic teaching hardware reused from the user's Home Lab Workshop project. Blender-authored; models are not manufacturer CAD or exact branded replicas.
- `assets/lab-three.js`: Home Lab's bundled Three.js, loaders, controls and utilities. Preserve `assets/three-license.txt`.
- `assets/lab-wallpaper-windows-bloom.jpg`: reused Home Lab teaching desktop artwork.
- Ubuntu wallpaper and Yaru icons: reused Home Lab assets with their accompanying attribution/license notices preserved. Unused icons are kept as the small OS artwork set for future work.
- The room, desk, rack, reference posters, live screen artwork, desktop monitor, Orbit mark and CSS helper orb are project-authored geometry/graphics. The interface draws these at runtime; it is not a static room photograph.
- `assets/python`: official `pyodide@314.0.7` npm distribution, pinned and self-hosted. Runtime source and notices: [Pyodide](https://github.com/pyodide/pyodide/tree/314.0.7), `assets/python/LICENSE`, and `assets/python/PYTHON-LICENSE`. The tarball integrity is SHA-1 `19a6865259f8d594cdef5b7e2f44930b68f5e987`. Binary/runtime files remain unmodified.

OS/product names identify the subjects being taught. No endorsement or official product affiliation is claimed.
